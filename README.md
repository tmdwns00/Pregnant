# 토닥 (가칭) — 임신·출산 부부 공용 앱 MVP 프로토타입

임신 주차별 안내, 자동 저장 일기, 화면이 꺼져도 멈추지 않는 진통 측정을 중심으로 한 웹 프로토타입입니다.
서버 없이 브라우저에만 저장되며(localStorage), 휴대폰 화면 크기에 맞춰 만들었습니다.

## 실행

```bash
cd prototype
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기 (휴대폰은 같은 Wi-Fi에서 PC IP로 접속)
```

## 구현 범위

| 기능 | 상태 |
| --- | --- |
| F01 온보딩(예정일/마지막 생리일/현재 주수, 역할, 건강정보 별도 동의) | 구현 |
| F02 주차별 홈 카드(아기 크기, 아기 시점 한마디, 몸 변화, 할 일 체크) | 구현 (샘플 콘텐츠, 의료 감수 전) |
| F03 부부 연동·실시간 공유 | 업데이트 예정 (서버 필요) |
| F04 자동 저장 일기(기분, 사진 회전·삭제, 아기에게 한 마디) | 구현 |
| F05 진통 측정(절대 시각 기록, 5-1-1/4-1-1 안내, 화면 꺼짐 방지, 취소, 세션 보관, 병원 전화) | 구현 / 잠금화면 표시·배우자 알림은 업데이트 예정 |
| F06 검진·일정 | 구현 / 알림·공유·캘린더 연동은 업데이트 예정 |
| F07 지원제도 체크리스트 | 구현 (2026년 11월 공개 자료 기준, 공식 확인 필요) |
| F08 체중·증상·태동 기록, 진료용 요약 | 구현 |
| 영양 챙기기 애니메이션(입 → 식도 → 위·장 흡수 → 혈액 → 태반·탯줄 → 아기) | 구현 (신규 아이디어) |
| 초음파 앨범·OCR, 가족 공유, 출산 가방, 우울 자가검진, 육아 모드, 포토북, 동기 모임, 임신 준비 모드, 다국어 | 업데이트 예정 |

## 파일

- `prototype/index.html` — 화면 뼈대와 하단 탭
- `prototype/app.js` — 화면, 저장, 진통 측정 로직
- `prototype/nutrition.js` — 영양 전달 애니메이션
- `prototype/data.js` — 주차별 샘플 콘텐츠, 영양 항목, 지원제도
- `prototype/styles.css` — 스타일(다크 모드 포함)

## 주의

- 건강 정보는 일반적인 안내이며 의료진의 진료를 대신하지 않습니다. 콘텐츠는 출시 전 전문의 감수가 필요합니다.
- 진통 측정은 브라우저 한계로 잠금화면 표시가 없습니다. 기록은 누른 시각을 그대로 저장하므로 화면이 꺼져도 정확합니다.
